# Java Photo Editor - Документация

## Обзор проекта

Современный фоторедактор, разработанный на Java с использованием JavaFX. Приложение предоставляет базовый набор инструментов для редактирования изображений.

## Архитектурные решения

### Почему выбрана архитектура MVVM (Model-View-ViewModel)

1. **Разделение ответственности**: 
   - Model (ImageModel) хранит данные о изображении
   - View (MainView) отвечает только за отображение UI
   - ViewModel (EditorViewModel) связывает модель и представление

2. **Тестируемость**: Каждый компонент можно тестировать изолированно

3. **Поддерживаемость**: Легко добавлять новые функции без изменения существующего кода

### Почему JavaFX вместо Swing

1. **Современный API**: JavaFX предоставляет более современный и гибкий API
2. **CSS стилизация**: Возможность использовать CSS для оформления интерфейса
3. **Property Binding**: Встроенная поддержка реактивного программирования через Properties
4. **Лучшая производительность**: Аппаратное ускорение графики

### Почему выбраны сервисы (FilterService, ImageFileService)

1. **Принцип единственной ответственности (SRP)**: Каждый сервис отвечает за одну задачу
2. **Переиспользуемость**: Сервисы можно использовать в разных частях приложения
3. **Тестируемость**: Легко написать юнит-тесты для каждого сервиса

### Структура пакетов

```
com.editor/
├── model/           # Модели данных
│   └── ImageModel   # Модель изображения
├── service/         # Бизнес-логика
│   ├── FilterService      # Применение фильтров
│   └── ImageFileService   # Работа с файлами
├── viewmodel/       # ViewModel для MVVM
│   └── EditorViewModel
├── view/            # UI компоненты
│   └── MainView
└── PhotoEditorApp   # Точка входа
```

## Функциональность

### Поддерживаемые форматы
- JPEG/JPG
- PNG
- GIF
- BMP
- WebP

### Фильтры и эффекты
1. **Яркость** - регулировка яркости изображения (0.0 - 2.0)
2. **Контраст** - регулировка контраста (0.0 - 3.0)
3. **Оттенки серого** - конвертация в черно-белое изображение
4. **Инверсия** - инвертирование цветов
5. **Поворот** - поворот на 90 градусов
6. **Отражение** - горизонтальное и вертикальное отражение

## Сборка и запуск

### Требования
- Java 17 или выше
- Maven 3.6+

### Сборка
```bash
mvn clean package
```

### Запуск
```bash
mvn javafx:run
```

### Запуск тестов
```bash
mvn test
```

## Зависимости

- **JavaFX 21.0.1** - GUI фреймворк
- **JUnit 5.10.1** - Фреймворк для тестирования
- **Mockito 5.8.0** - Библиотека для мокирования
- **TestFX 4.0.18** - Тестирование JavaFX приложений

## Расширение функциональности

Для добавления нового фильтра:

1. Добавьте метод в `FilterService.java`
2. Добавьте кнопку в `MainView.java`
3. Добавьте обработчик в `EditorViewModel.java`

Пример добавления фильтра размытия:

```java
// В FilterService.java
public Image applyBlur(Image image, int radius) {
    // реализация
}

// В EditorViewModel.java
public void applyBlur(int radius) {
    Image current = imageModel.getCurrentImage();
    if (current != null) {
        Image result = filterService.applyBlur(current, radius);
        imageModel.setCurrentImage(result);
    }
}
```
